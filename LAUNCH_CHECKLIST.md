# Launch Checklist

Do not mark the project launch-ready while any critical item below remains incomplete. Check items only after real, manual verification in the deployed application — not because code exists.

## Product

- [ ] All essential flows complete
- [ ] No dead buttons
- [ ] No placeholder pages
- [ ] No fake completion states
- [ ] No broken links
- [ ] Helpful empty states
- [ ] Helpful errors

## Curriculum

- [ ] Minimum lesson count complete (30+)
- [ ] Minimum mission count complete (100+)
- [ ] Code validated
- [ ] Tests validated
- [ ] Hints complete
- [ ] Solutions complete
- [ ] Skill mappings complete
- [ ] Prerequisites valid

## Security

- [ ] Authorization reviewed
- [ ] Rate limits active
- [ ] Secrets protected
- [ ] Security headers active
- [ ] Dependency audit reviewed
- [ ] Code sandbox reviewed
- [ ] Threat model complete

## Data

- [ ] Migrations complete
- [ ] Seed complete
- [ ] Backups configured
- [ ] Restore tested
- [ ] Constraints validated

## Quality

- [ ] Tests passing
- [ ] Type checks passing
- [ ] Lint passing
- [ ] Build passing
- [ ] Accessibility reviewed
- [ ] Responsive layouts reviewed
- [ ] Performance reviewed

## Operations

- [ ] Railway deployed
- [ ] Domain configured or temporary domain documented
- [ ] Health checks active
- [ ] Logging active
- [ ] Error tracking active
- [ ] Rollback documented
- [ ] Owner access verified

## Production Deployment Check

- [ ] Clean production build created
- [ ] All tests run
- [ ] Migration run against a clean database
- [ ] Launch curriculum seeded
- [ ] Owner account created securely
- [ ] Deployed to Railway
- [ ] Health endpoint verified
- [ ] Sign-in verified
- [ ] Onboarding verified
- [ ] Lesson completion verified
- [ ] Code mission completion verified
- [ ] XP update verified
- [ ] Mastery update verified
- [ ] Review generation verified
- [ ] Notes verified
- [ ] Bookmark verified
- [ ] Admin permissions verified
- [ ] Test lesson published
- [ ] Learner visibility verified
- [ ] Unauthorized access blocked verified
- [ ] Mobile layout verified
- [ ] Error tracking verified
- [ ] Logs contain no secrets verified
- [ ] Database backup process verified
- [ ] Rollback instructions verified
