# CodeQuest Academy

This repository contains **CodeQuest Academy**, a private, game-based, full-stack coding education platform built to teach a real developer skill set from the ground up — reading code, writing code, debugging, using Git and GitHub, understanding databases and APIs, and deploying real applications.

This is not a video course or a quiz app. It is designed as an interactive, mission-based learning game where progress is tracked through lessons, coding missions, skill mastery, and real capstone projects.

## Status

This repository currently contains planning and specification documents only. Implementation has not yet begun. See `PROJECT_STATUS.md` for the current build phase and `LAUNCH_CHECKLIST.md` for launch readiness tracking.

## Planned Technology Stack

- Next.js (App Router) with TypeScript in strict mode
- React
- PostgreSQL
- Prisma ORM
- Tailwind CSS
- Zod for validation
- GitHub for source control and CI (GitHub Actions)
- Railway for application and PostgreSQL hosting
